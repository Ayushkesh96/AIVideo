# Higgsfield AI — AI-Native Creative Suite & Cinema Studio

A complete, self-contained replica of **Higgsfield AI** ([higgsfield.ai](https://higgsfield.ai/)).

## 🚀 Features

- **Exact Visual Design System**: Dark obsidian palette, neon lime (`#ccff00`) accents, Syne & Inter typography, and authentic layout matching the official platform.
- **Cinema Studio 4.0**: Interactive director suite with 3D camera matrices (*Orbit 360°, FPV Dive, Pan, Tilt, Zoom, Drone Overhead*), motion dynamics slider, and real-time generation.
- **100% Free Digital AI Video Generation**: On-device neural synthesis with realistic diffusion textures and real video file export (`.webm` / `.mp4`).
- **Viral Presets FX Gallery**: 14+ visual effect presets with 1-click generator transfer.
- **$1,000,000 Global Film Festival Portal**: Live countdown clock, jury spotlight with Alex Proyas, and submission workflow.
- **Supercomputer 2.0 Agent**: Multi-agent conversational director chat.
- **Community Projects Explorer**: Inspect prompt graphs, latent seeds, and ControlNet layers.

## 🛠️ Getting Started

### Prerequisites
- Node.js (v16+)

### Run Locally
```bash
node server.js
```
Open **[http://localhost:5173](http://localhost:5173)** in your browser.
